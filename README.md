# Lexxify OPAQUE site

This repository contains the public product and marketing site for Lexxify OPAQUE.

- Intended domain: [opaque.lexxify.com](https://opaque.lexxify.com)
- Documentation: [everlexx.docs.page/lexxify-opaque-docs](https://everlexx.docs.page/lexxify-opaque-docs)
- Canonical source (private): [everlexx/lexxify-opaque](https://github.com/everlexx/lexxify-opaque)

Source access is invitation-based for qualified technical evaluation and customers.

The site is dependency-free static HTML and CSS. Lexxify OPAQUE is deployed in Lexxify Hub on iOS and Android through release `v0.1.2`. Deployment of the site itself is not performed by this task, and the intended site URL may not yet be live.
