04 / Protocol shape

Register and log in without turning protocol state into product magic.

The package exposes the real client/server calls. The application carries messages between them and creates its own authenticated session after protocol completion.

Server responseWASM/server operation

Protocol completion is not application authorization. Transport, record storage, session/token design, and access policy remain with the consuming application.
